# ConfIt v0.8.1 design

Design spec behind v0.8.1.

Status: Proposed

## Motivation

v0.8 landed the memory goal and I shipped the behavior while
forgetting everything around it. Stubs describe the old surface. The
spec declares the old version. Comments describe deleted shapes. Gaps
hid in the rush too. From v0.5 to v0.8 I added and added but never
paid. Since I am in there fixing all that, I pay the tech debt
beside it. Static analysis tools like mete plus an audit
through opencode found 76 findings across docs, placement, and
complexity.

## Objective

Pay the tech debt accumulated from v0.5 to v0.8. Without touching
the actual confit behavior.

## Goals

- Scaffold the nerd fonts stub beside the other three, so init covers
  every shipped plugin.
- Teach the stubs the v0.8 surface, so the editor completes `changed`
  and `requires` and package options and the three-zone jail.
- Declare Spec-Version 0.8.0 and align the drifted pages, so the spec
  matches the crates.
- Describe each item in its doc comment, so no comment documents a
  deleted neighbor.
- Validate `requires` beside `when` and `checks`, so unknown names fail
  the plan in every slot.
- Name the condition kinds in stubs and errors, so the editor warns
  before the plan fails.
- Poison every combinator, so nesting never hides the apply-time kind.
- Finish the streaming job across bundle reading, writing, and drift
  comparison, so the peak drops toward 1 MB instead of holding
  at 300 MB.
- Seat each behavior in its home module, so pure data stays apart
  from the code that runs it.
- Fold long signatures into their owning types, so calls name the
  thing instead of threading its parts.
- Split bool dispatchers into named verbs, so each function does
  one thing under its own name.

## Plan

### Stubs catch up

Init scaffolds the nerd fonts stub in the same order the engine lists
its plugins. The runtime stub gains the `changed` gate, the hook stub
gains the `requires` slot, the mise twin gains package options, the
resources stub teaches all three jail zones on every loader, and the
document stub scopes `unmanaged` and names callback args for what the
code passes.

### Spec tells the 0.8 truth

The banner declares 0.8.0 and the tracking sentence follows it. The
plan lead previews by default instead of promising storage. Manifests
hold hashes and sizes pointing into the pool, never serialized refs.
Loaders admit root-relative paths and absolute paths under the cache
and the extract root on every page that names them.

### Comments describe their items

Remnants reattach to the item below them or leave. Algorithm narration
moves into bodies or leaves. Summaries state the contract without input
branches. Arguments sections hold only invariants the types leave out.

### Validation covers all three slots

Unknown document names fail the plan in `requires` the way they
already do in `when` and `checks`. The check stays one shape across
slots, so a typo reads the same everywhere.

### Conditions carry their kind

Two kinds cover every condition. RuntimeCheck runs anywhere. ApplyCheck
needs plan and apply facts, and `changed` builds it. Every combinator
returns the apply kind when any member carries it, no matter the depth,
so nesting never launders the kind away. The stubs overload on the
kinds, so the editor underlines the mismatch where it is written. The
plan-time rejection stays as backstop and speaks the same names, so
the error repeats what the editor already said.

This is an editor good-to-have, not a company contract. Confit fits
people with free time to configure a machine as code, and those people
live in editors. The language server warning earns its place there.
Rust types do not change, and no test asserts the warning itself.
Propagation plus the renamed error shape carry ordinary unit tests.

### Finish the streaming job

v0.8 took the peak from GBs to 300 MB and that work holds. Reviewing
the audit places showed some pipeline parts I forgot, loading whole
bundles where the rest already streams. That leftover is why the peak
holds at 300 MB instead of dropping near 1 MB. This is a native app,
not an electron app, so 300 MB stays too high.

Reading decodes one entry at a time, spills each blob to its temp ref
before touching the next, and hashes while copying. Writing streams
entries into the archive instead of accumulating the whole. Drift
compares in chunks with the hash updating along the read. Behavior
stays identical and plans render the same bytes. Only the peak drops.

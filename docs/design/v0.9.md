# ConfIt v0.9 design

Design spec behind v0.9.

Status: In progress

## Motivation

Even at 300 MB the tool eats like an electron app
while doing a cli job. I installed mete and worked through
the findings beside the agent, and the architecture
failed in three places at once.

I stated that effects happen in cli alone, but they
scattered across every module behind the filesystem
seam. The seam kept test code clean and blurred
ownership and domain instead. Surface code, supposed
to only translate Lua into Rust, held a 500 line file
uncompressing data.

Core did everything, literally everything. Cli called
core for everything. Core held the effects, the data
transforms, the logic, the shared entities. Everything
else lived inside it, beside Lua evaluation and parts
of compression.

v0.8 lowered memory use and left its base in place. I
killed whole-bundle materialization, but the code
materialized everything everywhere. Lua held it in
gc, Rust held it several times over for comparisons
and through the whole run, downloads, archives and
their contents, whole trees. The seam I built returned
Vectors, closing every streaming path even where I
wanted it open.

The app grew more complex with a blurrier domain at
every step. The resource idea lived in my head, and
telling a resource (profile input) apart from a
route (profile output) stayed hard. Seams tested well
and traveled terribly, I carried them everywhere and
rewrote large portions to change small things.
Stopping 0.8.1 for 0.9 was forced. Making it lazy
meant blowing up nearly 80% of the code, and the
integration tests died in the same move for depending
on everything.

## Objective

Make the domain clear. Split apply-time resources from
plan-time resources. Simplify seams, so one
implementation serves runs and tests. Lazy filesystem
access.
Split responsibilities across crates and across
modules. Each work happens once. Trusted sources,
invalid states unrepresentable.

## Goals

- Seal identity once, so every layer trusts the
  sealed type and validation runs once at the edge.
- Part plan-time resources from apply-time documents,
  so inputs and outputs stop sharing one shape.
- Preview while the disk stays as found, so persistent
  storage reads untouched.
- Bind destinations late, so bundles travel users and
  platforms.
- Thin the surface to handles, so handles carry every
  crossing between layers.
- Stream where bytes run big, so archives and blobs
  travel in chunks.
- Fail old artifacts loud, so each version owns its
  shapes.

## Plan

### Identity seals at birth

The v0.4 split divided by dependency class before I
knew the domain, and I regretted centralizing
everything as pure data behind one seam for all
files. This split divides by domain after knowing it.
Trusted sources arrive with their hash and every
layer downstream trusts the type instead of
re-proving the bytes. The types admit only valid
states.

### Plan-time and apply-time part ways

Profiles eat resources and return documents, two
worlds meeting at evaluation. Resources feed the
plan as urls, project files, and archive members,
everything Lua reads to decide. Documents exist past it.
Payloads land at routes on the applying host. The old blur
merged both into paths, so inputs and outputs shared
one shape and every layer re-proved them. Each world
owns its nouns, and everything crosses the
evaluation edge sealed.

### Crates follow the domain

The filesystem speaks one shape with tests riding the
guard beside the single implementation. The model
holds the portable language, standing on data alone.
The store keeps pools, caches, slots, and bundles.
The runtime touches destinations alone. The engine
translates Lua over handles. The cli wires runs. Each
side announces its own deeds where they land, and
each caller stays inside its own verbs.

### Surface shape

Handles cross the Lua boundary as userdata with
methods. One fetch seals urls and project files alike,
and the caller picks a view. Text loads raw bytes,
open to whatever they hold. Structured answers come
from one decode. Content failures answer nil plus a
message, misuse throws.

```lua
local res = confit.fetch("https://example.com/starship.toml")
local body = res:text()
local data, err = res:load()
if data == nil then
  error(err)
end
```

Trees grow from sealed archives. The picker receives
one member handle per entry and answers nil, true, or
a table, so handles carry every crossing. Destinations
ride routes beside every pick.

```lua
local archive, err = confit.fetch(tarball_url):archive()
if archive == nil then
  error(err)
end
local dest = confit.path.home(".local/kitty.app")
local app = archive:tree(dest, function(member)
  local name = member:name()
  if name:match("%.ttf$") then
    return member:keep()
  end
  if name:match("%.txt$") then
    return true
  end
  return { path = "docs/" .. name }
end)
```

Single members pool through opaque with an explicit
mode on the document. A missing member answers nil
plus its name, and the plugin throws it attributed.

```lua
local member, err = archive:member("mise/bin/mise")
if member == nil then
  confit.plugin.helpers.error("mise tarball shape changed: " .. err)
end
local dest = confit.path.home(".local/bin/mise")
confit.document.opaque(dest, member, { mode = "755" })
```

### Streaming posture

Archives unpack entry by entry, blobs gzip streamed
from files, drift labels opaque payloads from hashes
alone. Text and structured payloads stay inline in the
manifest as data, rendered and compared in memory.
